# Q1 ONNX Motion Tracking 推荐部署流程

本文档描述**全程低层关节控制**下，从机器人上电到执行 ONNX motion tracking 的推荐流程。核心原则：

```text
整个流程只允许一个低层 /aima/hal/joint/command 命令源
官方高层 STAND_UP / BIPED_STAND_DEFAULT / BIPED_WALK_RUN 必须完全退出
ONNX 脚本不会自行起身；起身、承重和初始平衡由人工/吊装保护负责
```

## 0. 离线 preflight：先区分流水线验证与接触验证

在接近真机前，先运行 stand + mimic 双策略 headless 回归。建议使用包含 22 DoF `joint_names`、`dof_pos`、`dof_vel` 的 `_raw.pkl` motion。

```bash
python scripts/test_q1_dual_policy_mujoco_headless.py \
  --stand-policy-path policies/stand/model_8000.onnx \
  --stand-motion-file motions/stand/standv2_raw.pkl \
  --stand-config config/q1_sim2real_base.yaml \
  --mimic-policy-path policies/lateral_raise/model_6000.onnx \
  --mimic-motion-file motions/lateral_raise/lateral_raise_ref_motion_raw.pkl \
  --mimic-config config/q1_sim2real_base.yaml \
  --urdf robots/q1/q1_22dof_box.urdf \
  --robot-yaml robots/q1/q1_22dof.yaml \
  --output logs/q1_dual_policy_headless.npz \
  --summary-output logs/q1_dual_policy_headless_summary.yaml \
  --control-mode kinematic
```

这个 fixed-root kinematic 模式只验收 ONNX 365→22、history/phase、mimic 22 DoF、stand shadow inference、状态机和 target safety。其渲染视频不能证明机器人落地或能动力学站立。

要看地面接触，必须改为同一个带 floor/collision/freejoint 的物理 MJCF：

```bash
python scripts/test_q1_dual_policy_mujoco_headless.py \
  ...相同的 stand/mimic 参数... \
  --physics-mjcf /path/to/q1.xml \
  --control-mode pd \
  --free-root \
  --video-output logs/q1_dual_policy_contact.mp4
```

该模式会在首次 stand ONNX inference 前施加临时外力辅助，并在首次 stand target 生成后撤销。它是 sim2sim 接触测试，不是止跌、真机或人身安全验证。

### 当前 post-mimic handoff 状态

当前脚本使用 `--post-handoff-s 0.5` 的 minimum-jerk lower-body handoff，并以实际 command target 作为起点；upper body 保持该实际尾命令，而不是 measured q。首帧多腿硬跳和 measured-q 上身端点跳变已消除。

但在当前自由根 PD 物理模型中，latest stand lower target 在 handoff 尾端仍可快速移动，导致 ankle pitch 出现局部 `0.08 rad` safety clamp。**在此问题解决前，禁止将其解释为可真机无保护放手的 handoff。** 后续必须在以下两种明确方案中选择其一：延长 handoff/post hold，或增加 handoff 专用的连续 stand-reference filter；不得擅自全局降低 `max_target_step_rad`。

## 真机低层流程（唯一推荐）

### 1. 上电并确认高层完全退出

机器人上电后，先确认没有官方高层控制模块或速度 example 正在占用机器人。不得让以下状态/程序继续发控制：

```text
STAND_UP
BIPED_STAND_DEFAULT
BIPED_WALK_RUN
mc_locomotion_velocity.py
任何官方高层 action / velocity source
```

切换到低层开发/低层控制模式后，本流程唯一允许的命令源是：

```text
/aima/hal/joint/command
```

### 2. 人工/吊装建立初始站姿

ONNX 脚本不能把瘫倒机器人从地上起身。必须由人工扶持或吊装使机器人接近竖直，并让脚底逐步接触地面。全程至少一人保护，并准备外部急停。

进入下一步前确认：

```text
身体接近竖直
脚底接近或已经接触地面
没有高层控制输入
可以随时重新吊起或切断低层控制
```

### 3. 低层 dry-run

先不开电机，仅检查 policy、topic、IMU 和 joint state：

```bash
cd ~/q1_asap_2real
source /path/to/q1_ros2_ws/install/setup.bash

python scripts/sim2real_q1_motion_tracking_ros2.py \
  --stand-policy-path policies/stand/model_8000.onnx \
  --stand-motion-file motions/stand/standv2_raw.pkl \
  --stand-config config/q1_sim2real_base.yaml \
  --mimic-policy-path policies/lateral_raise/model_6000.onnx \
  --mimic-motion-file motions/lateral_raise/lateral_raise_ref_motion_raw.pkl \
  --mimic-config config/q1_sim2real_base.yaml \
  --urdf robots/q1/q1_22dof_box.urdf \
  --robot-yaml robots/q1/q1_22dof.yaml \
  --enable-policy \
  --dry-run
```

确认：

```text
state=HOLD_CURRENT
joint_age 与 base_age 持续刷新
projected_gravity 静止时接近 [0, 0, -1]
ONNX input=[1,365]，output=[1,22]
关节名称、顺序和 IMU 坐标系正确
```

### 4. 低层开电机，但保持人工/吊装保护

关闭 `--dry-run`，再明确开启低层电机控制：

```bash
python scripts/sim2real_q1_motion_tracking_ros2.py \
  --stand-policy-path policies/stand/model_8000.onnx \
  --stand-motion-file motions/stand/standv2_raw.pkl \
  --stand-config config/q1_sim2real_base.yaml \
  --mimic-policy-path policies/lateral_raise/model_6000.onnx \
  --mimic-motion-file motions/lateral_raise/lateral_raise_ref_motion_raw.pkl \
  --mimic-config config/q1_sim2real_base.yaml \
  --urdf robots/q1/q1_22dof_box.urdf \
  --robot-yaml robots/q1/q1_22dof.yaml \
  --enable-policy \
  --enable-motors \
  --risk-confirm I_UNDERSTAND_REAL_ROBOT_RISK \
  --get-ready-duration-s 5.0 \
  --max-command-step-rad 0.005
```

脚本进入 `WAIT_STATE -> HOLD_CURRENT` 后，仍由人/吊装承担防倒；`HOLD_CURRENT` 只保持当前关节角，不是平衡控制器。

### 5. 低层 stand，再执行 mimic

```text
1. 人保持保护，按 i：GET_READY，慢速对齐 default_dof_pos
2. 确认脚底承重、姿态正确、无明显抖动
3. 按 ]：STAND_POLICY；先观察 stand policy
4. 只有 stand 确实稳定且仍有人保护时，按 [：开始 mimic 过渡
5. 需要提前退出 mimic 时按 o：进入 post handoff
6. 异常时按 q：EMERGENCY_DAMPING，并立即人工保护/急停
```

当前 physical post-handoff 尚未完成验证，禁止把这套流程理解为可以无保护放手。

## 禁止流程

不要这样做：

```text
机器人瘫倒在地
-> 直接启动低层 ONNX
-> 按 i / ] / [
```

也不要这样做：

```text
官方 BIPED_WALK_RUN / BIPED_STAND_DEFAULT 仍在控制
-> 同时启动 ONNX 低层 /aima/hal/joint/command
```

这两种情况都可能导致控制冲突、异常震颤或硬件风险。

## 按键说明

```text
i = 插值到默认站立位姿（GET_READY）
] = 进入 STAND_POLICY
[ = 开始 mimic 过渡
o = 从 mimic/pre-mimic 安全返回 post handoff
q = 紧急阻尼
```

## 一句话总结

```text
先用人工/吊装把机器人变成“已经竖直、接近站稳”的状态，
再切低层，让 ONNX 脚本 HOLD_CURRENT，
然后按 i 对齐默认姿态，
按 ] 先运行 stand policy，确认稳定后才按 [ 执行 mimic。
```
